# 🏃 快速开始指南

> 5 步启动 BrainDance 开发环境 - 30 分钟内跑通整个系统

本指南旨在帮助您快速搭建 BrainDance 开发环境。通过以下 5 个步骤，您将能够在 30 分钟内启动完整的开发环境，包括 Supabase 本地服务、AI Worker 和 Edge Functions。

**前置要求**：
- 操作系统：Windows WSL2 / Linux / macOS
- 硬件：NVIDIA GPU（RTX 3060 或更高，至少 8GB 显存）
- 存储空间：至少 50GB 可用空间

## 🛠️ 步骤 1：环境准备

### 1.1 安装必需软件

在开始之前，请确保您的系统已安装以下软件：

#### Docker Desktop

**Windows WSL2 / macOS**:
1. 下载并安装 [Docker Desktop](https://www.docker.com/products/docker-desktop)
2. 启动 Docker Desktop
3. 验证安装：
   ```bash
   docker --version
   # 预期输出：Docker version 24.x.x 或更高
   ```

**Linux**:
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install docker.io docker-compose
sudo systemctl start docker
sudo usermod -aG docker $USER
```

#### Supabase CLI

**Windows (WSL2)**:
```bash
# 使用 npm 安装
npm install -g @supabase/cli

# 或使用 Homebrew (macOS/Linux WSL2)
brew install supabase/tap/supabase
```

验证安装：
```bash
supabase --version
# 预期输出：@supabase/cli version 1.x.x 或更高
```

#### Conda (Python 环境管理)

**推荐**：使用 Miniconda 或 Anaconda

**安装 Miniconda**:
```bash
# Linux/macOS/WSL2
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh

# 验证安装
conda --version
# 预期输出：conda 24.x.x 或更高
```

#### Git

```bash
# Windows/macOS/Linux
git --version
# 预期输出：git version 2.x.x 或更高

# 如果未安装，请先安装 Git
# Windows: https://git-scm.com/download/win
# macOS: brew install git
# Linux: sudo apt-get install git
```

### 1.2 验证硬件要求

#### 验证 GPU

```bash
# Linux/WSL2
nvidia-smi

# 检查 CUDA 版本
nvcc --version
```

**预期输出**：
```
+-----------------------------------------------------------------------------+
| NVIDIA-SMI 5xx.xx    Driver Version: 5xx.xx    CUDA Version: 12.x          |
|-------------------------------+----------------------+----------------------+
| GPU  Name        Persistence-M| Bus-Id        Disp.A | Volatile Uncorr. ECC |
| Fan  Temp  Perf  Pwr:Usage/Cap|         Memory-Usage | GPU-Util  Compute M. |
|===============================+======================+======================|
|   0  RTX 5070           On   | 00000000:01:00.0  On |                  N/A |
+-------------------------------+----------------------+----------------------+
```

**要求**：
- GPU 显存：至少 8GB（推荐 12GB+）
- CUDA 版本：11.8 或 12.x

#### 验证存储空间

```bash
# Linux/macOS/WSL2
df -h

# 预期输出：根分区至少有 50GB 可用空间
```

### 1.3 克隆项目

```bash
# 安装并初始化 Git LFS（仅首次需要）
git lfs install

# 克隆 BrainDance（必须包含全部子模块）
git clone --recurse-submodules https://github.com/tianxingleo/BrainDance.git

# 进入项目目录
cd BrainDance

# 拉取 LFS 大文件（主仓库 + 所有子模块）
git lfs pull
git submodule foreach --recursive 'git lfs pull || true'

# 验证克隆成功
ls -la
# 应该看到：README.md, ai_engine/, supabase/, docs/ 等目录

# 验证子模块状态
git submodule status --recursive
```

## 📦 步骤 2：安装依赖

### 2.1 安装 Python 依赖

#### 创建 Conda 环境

```bash
# 创建新的 Conda 环境
conda create -n braindance python=3.10

# 激活环境
conda activate braindance

# 验证 Python 版本
python --version
# 预期输出：Python 3.10.x
```

#### 安装 PyTorch

**根据您的 CUDA 版本选择安装命令**：

**CUDA 12.x**:
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu120
```

**CUDA 11.8**:
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

验证安装：
```bash
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA: {torch.cuda.is_available()}')"
# 预期输出：
# PyTorch: 2.x.x+cu118
# CUDA: True
```

#### 安装 AI Engine 依赖

```bash
# 进入 AI Engine 目录
cd ai_engine/3dgs

# 如果不是通过 --recurse-submodules 克隆，可补执行：
# git submodule sync --recursive
# git submodule update --init --recursive

# 安装项目依赖
pip install -r requirements.txt

# 强制使用仓库内 nerfstudio（含项目补丁）
pip uninstall -y nerfstudio
pip install -e src/libs/nerfstudio

# 验证安装来源
python -c "import nerfstudio, pathlib; print(pathlib.Path(nerfstudio.__file__).resolve())"
# 预期输出路径包含: ai_engine/3dgs/src/libs/nerfstudio
```

**主要依赖**：
- `nerfstudio` - 3DGS 训练框架
- `supabase` - Supabase Python SDK
- `python-dotenv` - 环境变量管理
- `dashscope` - 阿里云 DashScope SDK
- `ultralytics` - YOLO 目标检测
- `opencv-python` - 图像处理

### 2.2 安装 Supabase 依赖

Supabase CLI 和 Docker 已在步骤 1 中安装，这里只需验证：

```bash
# 验证 Supabase CLI
supabase --version

# 验证 Docker
docker --version
docker compose version
```

### 2.3 安装 Deno (用于 Edge Functions)

```bash
# Linux/macOS/WSL2
curl -fsSL https://deno.land/x/install/install.sh | sh

# 添加到 PATH (添加到 ~/.bashrc 或 ~/.zshrc)
export DENO_INSTALL="$HOME/.deno"
export PATH="$DENO_INSTALL/bin:$PATH"

# 验证安装
deno --version
# 预期输出：deno 1.x.x
```

### 3.2 配置环境变量

在 AI Engine 目录下创建 `.env` 文件：

```bash
# 返回项目根目录
cd ../ai_engine/3dgs

# 创建 .env 文件
cp .env.example .env

# 编辑 .env 文件
nano .env
```

填入以下配置：

```env
# Supabase 连接信息（从步骤 3.1 获取）
SUPABASE_URL=http://127.0.0.1:54321
SUPABASE_KEY=your_service_role_key_here  # 替换为实际的 SERVICE ROLE KEY

# 存储桶与表名配置
SUPABASE_BUCKET=braindance-assets
SUPABASE_TABLE=processing_tasks

# Flutter Recall 本地 AI 默认模型发布仓
LOCAL_LLM_MODEL_BUCKET=braindance-models
LOCAL_LLM_MODEL_OBJECT_PATH=releases/qwen3-1.7b-braindance-q5-k-m-imatrix.gguf

# DashScope API Key (用于 AI 场景理解)
# 从 https://dashscope.console.aliyun.com/ 获取
DASHSCOPE_API_KEY=sk-your-dashscope-api-key

# 3DGS 训练配置
MAX_IMAGES=500
TRAINING_ITERATIONS=15000
MIN_QUALITY_SCORE=40

# 日志配置
LOG_LEVEL=INFO
```

## 💾 备份与同步

### 使用一键同步脚本

BrainDance 提供了 `save.sh` 脚本，简化数据库结构、数据备份和代码提交流程。

**何时使用**：
- ✅ 安装了新的 PostgreSQL 插件（如 vector）
- ✅ 修改了数据库表结构
- ✅ 更新了 Deno Functions 代码
- ✅ 需要保存测试数据供队友使用

**执行方式**：
```bash
# 在项目根目录下执行（和 supabase 文件夹同级）

# 使用描述性名称（推荐）
./save.sh add_vector_support

# 或使用时间戳（自动生成）
./save.sh
```

**脚本会自动执行**：
1. 📜 生成数据库迁移文件
2. 🌱 更新种子数据
3. 💅 格式化 Deno Functions 代码
4. 📦 提交到 Git 本地仓库
5. ☁️ 推送到 GitHub（需手动执行 `git push`）

**注意**：脚本会自动提交到本地 Git，但需要手动执行 `git push` 推送到远程仓库。

### 队友如何恢复

队友（或你换了新电脑）只需两步：

```bash
# 1. Clone 仓库（含子模块 + LFS）
git lfs install
git clone --recurse-submodules https://github.com/yourusername/BrainDance.git
cd BrainDance
git lfs pull
git submodule foreach --recursive 'git lfs pull || true'

# 2. 一键启动
supabase start
```

Supabase 会自动应用所有迁移脚本和测试数据。

## ❓ 常见问题

### Q1: Docker 启动失败，提示端口占用

**问题**：Supabase 启动失败，提示端口 54321 或 54322 被占用。

**解决方案**：
```bash
# 检查占用端口的进程
sudo lsof -i :54321
sudo lsof -i :54322

# 停止占用端口的进程，或修改 supabase/config.toml 中的端口配置
```

### Q2: CUDA 版本不匹配

**问题**：PyTorch 无法识别 CUDA，或提示 CUDA 版本不匹配。

**解决方案**：
1. 检查 CUDA 版本：`nvidia-smi`
2. 重新安装匹配 CUDA 版本的 PyTorch：
   ```bash
   # 例如 CUDA 12.x
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu120
   ```

### Q3: Supabase 启动后 API 无响应

**问题**：Supabase 启动成功，但 API 返回连接拒绝。

**解决方案**：
```bash
# 检查 Docker 容器状态
docker ps | grep supabase

# 查看容器日志
docker compose logs -f

# 重启 Supabase
supabase stop
supabase start
```

### Q4: 缺少环境变量

**问题**：启动 Worker 时提示缺少环境变量。

**解决方案**：
1. 确保在 `ai_engine/3dgs` 目录下创建了 `.env` 文件
2. 检查 `.env` 文件中的 `SUPABASE_URL` 和 `SUPABASE_KEY` 是否正确
3. 重新激活 Conda 环境：`conda activate braindance`

### Q5: Edge Function 启动失败

**问题**：Edge Function 启动失败，提示找不到函数或配置错误。

**解决方案**：
```bash
# 确保在正确的目录下
cd supabase/functions/search-models

# 确保 .env.local 文件存在且包含 DASHSCOPE_API_KEY
cat .env.local

# 重新启动
supabase functions serve search-models --no-verify-jwt --env-file .env.local
```
