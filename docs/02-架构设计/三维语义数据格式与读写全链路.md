# 三维语义数据格式与读写全链路

本文档描述 BrainDance 项目中三维语义数据的完整格式规范，涵盖从原始采集到端侧渲染的全链路读写逻辑。

---

## 1. 数据格式总览

项目中的"三维语义数据"由以下几个部分组成：

| 层次 | 格式 | 用途 | 主要读写方 |
|------|------|------|------------|
| 三维几何 | `.ply` / `.splat` / `.ksplat` | 3D 高斯点云模型 | Python 后端写，Flutter/WebView 读 |
| 相机参数 | `transforms.json` / `webgl_poses.json` | 训练输入帧位姿、查看器相机位姿 | Python 写，WebView 读 |
| 语义标注 | PostgreSQL `model_assets` 表 | 文本描述、物体列表、标签、向量 | Python 写（KnowledgeBase），Flutter 读（RAG 搜索） |
| 分割掩码 | PNG (带 Alpha 透明通道) | 前景/背景分割结果 | Python 写（AISegmentor），Python 读（SAM3D） |
| 本地向量索引 | SQLite `braindance_memory_rag.db` | 端侧离线语义搜索缓存 | Flutter 写/读（LocalRagIndexService） |

## 2. 三维几何文件

### 2.1 PLY 格式（主格式）

3D Gaussian Splatting 训练输出的原始点云格式，使用 `plyfile` 库读写。

**文件结构（vertex 元素字段）：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `x`, `y`, `z` | float32 | 高斯中心位置（世界坐标） |
| `nx`, `ny`, `nz` | float32 | 法线（可选） |
| `f_dc_0`, `f_dc_1`, `f_dc_2` | float32 | 球谐函数 DC 分量 = 基础颜色 |
| `f_rest_*` | float32 | 球谐高阶分量（可选） |
| `opacity` | float32 | 不透明度（logit 空间，需 `sigmoid` 解码） |
| `scale_0`, `scale_1`, `scale_2` | float32 | 高斯尺度（log 空间，需 `exp` 解码） |
| `rot_0`, `rot_1`, `rot_2`, `rot_3` | float32 | 旋转四元数 `(w, x, y, z)` |

**关键编解码公式：**
- 不透明度：`opacity_real = 1 / (1 + exp(-raw_opacity))`
- 颜色：`color_rgb = (0.5 + 0.28209479 * sh_dc) * 255`
- 尺度：`scale_real = exp(raw_scale)`

**读取（`ply_utils.py`）：**
```python
from plyfile import PlyData
plydata = PlyData.read(ply_path)
vertex = plydata["vertex"]
positions = np.vstack((vertex["x"], vertex["y"], vertex["z"])).T
opacities = 1.0 / (1.0 + np.exp(-vertex["opacity"]))
```

**写入：**
- 训练产出：由 nerfstudio / 2DGS / Sparse2DGS 等训练引擎直接输出
- 后处理写入：`PlyData([PlyElement.describe(filtered_vertex, 'vertex')]).write(output_path)`

### 2.2 SPLAT 格式（移动端交付）

二进制紧凑格式，由 `compress_ply_to_splat()` 从 PLY 转换而来。

**二进制布局（每个高斯点，顺序存储）：**

| 偏移 | 长度 | 类型 | 内容 |
|------|------|------|------|
| 0 | 12 | float32 x 3 | 位置 `(x, y, z)` |
| 12 | 12 | float32 x 3 | 尺度 `(sx, sy, sz)`，已 `exp` 解码 |
| 24 | 4 | uint8 x 4 | RGBA 颜色 + 不透明度 |
| 28 | 4 | uint8 x 4 | 旋转四元数（归一化后映射到 `0~255`） |

**每个高斯点 32 字节，按到原点距离排序。**

转换逻辑（`ply_utils.py:compress_ply_to_splat`）：
1. 过滤低不透明度点（`opacity_threshold=0.05`）
2. 2DGS 输出只有 2 个 scale 时，自动补保守厚度轴
3. 颜色从球谐 DC 分量转 RGB，旋转四元数归一化后映射到 uint8

### 2.3 KSPLAT 格式（Web 交付）

通过 GaussianSplats3D 的 Node 工具从 PLY 转换，调用外部 `node` 命令。

### 2.4 格式转换入口

`compress_model_for_delivery()` 统一调度：
- `ply` → 不转换，原样使用
- `splat` → 调用 `compress_ply_to_splat()`（默认）
- `ksplat` → 调用 `convert_ply_to_ksplat()`

## 3. 相机参数文件

### 3.1 transforms.json（训练输入）

3DGS 训练引擎使用的相机参数文件。

```json
{
    "w": 1920,
    "h": 1080,
    "fl_x": 1731.594,
    "fl_y": 1736.933,
    "cx": 960.0,
    "cy": 540.0,
    "k1": -0.016,
    "k2": -0.021,
    "p1": 0.0,
    "p2": 0.003,
    "camera_model": "OPENCV",
    "frames": [
        {
            "file_path": "images/frame_00277.jpg",
            "transform_matrix": [
                [1.0, 0.0, 0.0, -0.755],
                [0.0, 1.0, 0.0, -1.802],
                [0.0, 0.0, 1.0, -0.578],
                [0.0, 0.0, 0.0, 1.0]
            ],
            "colmap_im_id": 235
        }
    ]
}
```

| 字段 | 说明 |
|------|------|
| `w`, `h` | 图像尺寸 |
| `fl_x`, `fl_y` | 焦距 |
| `cx`, `cy` | 光心 |
| `k1`, `k2`, `p1`, `p2` | 畸变系数 |
| `camera_model` | 相机模型（`OPENCV` / `PINHOLE`） |
| `frames[].file_path` | 图像相对路径 |
| `frames[].transform_matrix` | 4x4 外参矩阵（世界到相机） |

**读写方：** Python COLMAP/GLOMAP SfM 输出 → Python 训练引擎读取；AI 分割后更新 `frames` 列表（剔除不合格帧）。

### 3.2 webgl_poses.json（查看器位姿）

WebView 查看器使用的相机位姿文件，用于导航到指定视角。

由训练完成后后端生成，路径与模型文件同名但后缀替换为 `webgl_poses.json`。

## 4. 语义标注数据（PostgreSQL）

### 4.1 model_assets 表

完整的表结构（含多次 migration 后的字段）：

```sql
CREATE TABLE model_assets (
    id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    scene_id        text NOT NULL UNIQUE,       -- 场景唯一标识
    user_id         text,                        -- 用户 ID
    source_task_id  uuid,                        -- 来源任务 ID
    display_name    text,                        -- 展示名称
    description     text,                        -- AI 生成的自然语言描述
    objects         text[],                      -- 识别到的物体列表
    tags            text[],                      -- 语义标签列表
    embedding       vector(1536),                -- 1536 维向量（pgvector）

    ply_path        text,                        -- 云端 3D 模型路径
    preview_img_path text,                       -- 封面图路径

    meta_info       jsonb DEFAULT '{}',          -- 技术元数据
    agent_meta      jsonb DEFAULT '{}',          -- Agent 维护的元数据

    place_id        uuid,                        -- 物理地点标识（时间对比）
    memory_thread_id uuid,                       -- 记忆线程 ID
    version_label   text,                        -- 版本标签（如"毕业前"）
    summary_title   text,                        -- Agent 生成的回忆标题
    event_label     text,                        -- 事件标签（如"春节"）

    created_at      timestamptz DEFAULT now()
);
```

**meta_info 典型结构：**
```json
{
    "quality_score": 85,
    "quality_reason": "光照充足，纹理清晰",
    "engine_version": "nerfstudio-splatfacto",
    "initial_camera_pose": null,
    "is_ai_selected": false
}
```

### 4.2 向量生成与写入

**写入流程（`knowledge_base.py`）：**

1. 从 AI 分析结果中提取 `description`、`objects`、`tags`
2. 构造加权文本（Subject-First Strategy）：
   ```
   核心物体: {主物体}。 {主物体}。
   详细描述: {描述}。
   包含物品: {物品列表}。
   环境标签: {标签列表}。
   ```
3. 调用阿里云 `text-embedding-v2` 模型生成 1536 维向量
4. `upsert` 到 Supabase `model_assets` 表

**读取流程（语义搜索）：**

- 云端：调用 `match_model_assets()` RPC 函数，使用 HNSW 索引进行余弦相似度搜索
- 端侧：`LocalRagIndexService` 将数据同步到本地 SQLite，使用哈希向量 + 词法混合搜索

## 5. 分割掩码（Mask）

### 5.1 格式

PNG 图片，带 Alpha 通道。Alpha = 0 表示背景，255 表示前景。

### 5.2 生成流程

由 `AISegmentor`（AI 模式）或 `MaskGenerator`（推理模式）生成：

**AI 模式（`ai_segmentor.py`）：**
1. Qwen-VL-Plus 分析中心物体 → 生成英文检测提示词
2. YOLO-Worldv2 检测 → 选中心框
3. SAM 2.1 分割 → 合并 mask
4. 清洗验证（面积/形状/边缘质量）
5. 合成透明 PNG 并保存

**推理模式（`sam3d_engine/masking.py`）：**
1. 优先使用图片自带 Alpha 通道
2. `smart` 策略：YOLO-World + SAM 2.1
3. `simple` 策略：亮度阈值（白/黑背景去除）

### 5.3 写入（`_save_transparent_png`）

```python
img_bgra = cv2.merge([
    (b * alpha).astype(np.uint8),  # B × mask
    (g * alpha).astype(np.uint8),  # G × mask
    (r * alpha).astype(np.uint8),  # R × mask
    mask_blurred                     # Alpha = mask
])
cv2.imwrite(str(new_path), img_bgra)  # 保存为 .png
```

### 5.4 读取

`MaskGenerator.get_mask()` 读取时优先检测 Alpha 通道：
```python
img_pil = Image.open(image_path).convert("RGBA")
if np.array(img_pil)[:, :, 3].min() < 255:
    return np.array(img_pil)[:, :, 3]  # 直接使用 Alpha 作为 mask
```

## 6. 端侧本地向量索引

### 6.1 SQLite 表结构

`LocalRagIndexService` 在端侧维护的离线索引：

```sql
CREATE TABLE memory_scene_vectors (
    model_id        TEXT PRIMARY KEY,
    scene_id        TEXT NOT NULL,
    user_id         TEXT,
    searchable_text TEXT NOT NULL,   -- 可搜索文本（拼接 name + desc + tags + objects）
    vector_json     TEXT NOT NULL,   -- 向量 JSON 数组（哈希向量，192 维）
    payload_json    TEXT NOT NULL,   -- 完整模型数据 JSON
    fingerprint     TEXT NOT NULL,   -- 增量同步指纹
    updated_at      TEXT NOT NULL
);
```

### 6.2 搜索算法

混合打分：`score = cosine_sim × 0.82 + lexical_match × 0.18`

- 向量相似度：`HashingTextEmbedder` 生成 192 维哈希向量，点积近似余弦相似度
- 词法匹配：查询词在 `searchable_text` 中的命中比例
- 阈值：`minScore=0.12`，词法全命中（`0.9+`）时强制保留

### 6.3 增量同步

通过 `fingerprint` 字段判断是否需要更新：
```
fingerprint = "{created_at}|{preview_img_path}|{ply_path}|{searchable_text}"
```
仅在内容变化时重建向量并 `upsert`，已删除的云端模型会自动清理本地索引。

## 8. PLY 后处理操作

### 8.1 分位数切割（`perform_percentile_culling`）

去除 3DGS 训练后远处背景伪影：
1. 计算相机中心位置均值 = 场景中心
2. 计算所有高斯点到中心距离
3. 按 `keep_percentile`（默认 0.8）确定半径阈值
4. 联合过滤：`(距离 < 阈值) AND (不透明度 > 0.05)`

### 8.2 欧拉角旋转（`rotate_ply_vertices_euler`）

修正模型朝向（如 SAM3D 单图重建的 -90° X 轴旋转）：
- 对顶点坐标应用旋转矩阵
- 不修改高斯旋转属性（仅改位置）

### 8.3 X 轴 180° 旋转（`rotate_gaussian_ply_x180`）

整体翻转（前后 + 上下颠倒纠正）：
- 位置：`(x, y, z) → (x, -y, -z)`
- 旋转四元数：左乘 `qx180 = (0, 1, 0, 0)`

## 9. 全链路数据流

```
用户录制视频
    │
    ▼
视频抽帧 → images/*.jpg
    │
    ├─→ SfM (COLMAP/GLOMAP) → transforms.json（相机参数）
    │
    ├─→ AI 场景分析 (Qwen-VL) → score / description / objects / tags
    │
    ├─→ AI 语义分割 (YOLO + SAM) → masks / 透明 PNG
    │       └─ 不合格帧剔除，更新 transforms.json
    │
    ▼
3DGS 训练 → point_cloud.ply
    │
    ├─→ 后处理切割 → 去除背景伪影
    │
    ├─→ 格式转换 → .splat（移动端）/ .ksplat（Web）
    │
    ├─→ 向量化入库 (text-embedding-v2, 1536d) → model_assets 表
    │
    ├─→ 上传 Supabase Storage → ply_path / preview_img_path
    │
    ▼
Flutter 端侧
    ├─→ WebGL 查看器下载并渲染 .splat / .ply
    │       └─ WebView 加载，通过 JS bridge 传递模型 URL + 位姿
    │
    ├─→ 本地 RAG 索引同步 → SQLite (192d 哈希向量)
    │       └─ 混合搜索：向量相似度 82% + 词法匹配 18%
    │
    └─→ 语义搜索 / 时间对比 / 场景回忆
```
