### 项目简介

BrainDance（流光·记）是一个面向移动端的"可检索三维记忆库"项目。该项目利用 **3D Gaussian Splatting（高斯泼溅）** 等计算机图形学前沿技术，将现实世界的物理空间以 1:1 的高保真度转化为数字资产。结合 **Multimodal AI（多模态大模型）** 与 **RAG（检索增强生成）** 技术，BrainDance 让三维场景具备了"语义"，实现了"搜索现实世界"的能力。

**核心价值主张**：对抗时间熵增，为每个人、每座城留下一份可以穿越时间的空间档案。

## ❓ 常见问题

### Q: 我应该从哪里开始？

A: 如果您是团队成员，建议从 [README.md](../README.md) 开始，然后按照"快速上手"部分逐步深入。如果需要详细的环境配置，请参考 [开发环境配置](开发环境配置.md)。

### Q: 文档之间有冲突怎么办？

A: 以 docs/ 目录下的文档为准。其他目录的文档（如 ai_engine/README.md）是模块级别的参考文档，docs/ 目录下的文档是全局索引和核心文档。

### Q: 如何快速找到特定功能的文档？

A: 使用本文档的"文档目录索引"快速定位，或查看 [INDEX.md](INDEX.md) 获取全文搜索索引。

### Q: 文档中发现错误如何反馈？

A: 请在 GitHub Issues 中报告，我们会尽快修复。
