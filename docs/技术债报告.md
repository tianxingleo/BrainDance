## 一、项目概览

BrainDance（流光 · 记）是一个面向空间记忆的三维语义引擎与检索系统。核心链路为：移动端采集 -> 云端3D重建与语义理解 -> 移动端/Web端浏览、检索和回看。技术栈涵盖 Flutter (移动端)、Supabase/Deno (BaaS + Edge Functions)、Python (AI Worker + 3DGS)、Vue 3 (Dashboard)、Three.js (3D Viewer)。

## 三、影响演示稳定性的风险点（25个）

### A 类：高概率 / 高影响

1. **spatialAgent.ts 3917行巨型单文件** — Agent 全链路逻辑高度耦合
2. **model_assets 表未启用 RLS** — 任何人可读取全部模型数据
3. **community_posts 和 worker_nodes 的 RLS 全开放** — `USING (true) WITH CHECK (true)`
4. **app/.env 文件存在于工作区** — 密钥泄露风险
5. **Agent Recall 流式连接超时 300s 硬编码** — 网络不稳定时无响应
6. **webgl_viewer.dart 大量 127.0.0.1 硬编码** — 端口冲突时加载失败
7. **recall.dart 状态爆炸** — 50+ 状态变量通过 extension 混入
8. **94 处 catch 块静默吞异常** — 运行时错误无任何可追踪信息
9. **DASHSCOPE_API_KEY 未配置时 Agent 全链路不可用** — 无降级方案
10. **Flutter 端仅 1 个单元测试文件** — 无法发现回归问题

### B 类：中概率 / 中影响

11. **7 个 git submodule 依赖外部仓库** — 拉取失败导致 ai_engine 不可用
12. **LocalRagIndexService 用 sqflite 存 embedding** — 性能随数据量急剧下降
13. **record.dart 相机异常静默禁用** — 无用户提示
14. **community 页面 mock 数据与真实数据混用** — 展示不可控
15. **spatialAgent LLM 调用失败静默回退** — 复杂查询被误路由
16. **agent-recall 流式 2KB 空格 ping** — 特定网络环境卡住
17. **Supabase Deno std 版本过旧** — 部署兼容性问题
18. **Dashboard 无认证** — anon key 直连
19. **llamadart 0.6.6 版本可能不稳定** — 本地 AI 可能崩溃
20. **ai_engine/demo 大量输出缓存** — 仓库体积膨胀

### C 类：低概率 / 需关注

21. **多个超过 800 行的大文件** — 维护困难
22. **Supabase apiKey 回退链可能降级到 service_role** — 绕过 RLS
23. **embedding 维度硬编码 1536** — 与 OpenAI 绑定
24. **TemporalCompare Agent 跨模块 import** — 模块间耦合
25. **part/part of 耦合导致编译时间增长** — 开发体验下降

## 五、关键发现

1. **代码规模**：项目总代码量约 17 万行（不含文档），ai_engine 占 39%，app 占 13%
2. **最大技术债**：`spatialAgent.ts`（3917行）是全项目最关键也最脆弱的文件
3. **安全短板**：model_assets 无 RLS，community_posts/worker_nodes 全开放，Dashboard 无认证
4. **测试覆盖**：Flutter 端仅 1 个单元测试文件，AI Engine 和 Edge Functions 缺少自动化测试
5. **最大演示风险**：Agent Recall 链路依赖 DashScope API 密钥，无降级方案
6. **最高 ROI 任务**：L-7（补全 .env 文档）、L-1（结构注释）、M-3（降级提示）、M-4（端口检测）
