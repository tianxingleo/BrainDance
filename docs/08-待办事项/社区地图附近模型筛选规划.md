# 社区地图区域与标签二级筛选规划（2026-05-21）

## 1. 现状

当前 Flutter 社区页已经具备这条链路：
- `app/lib/pages/community.dart` 负责探索页、发现页、投稿页切换，也负责打开完整地图页。
- `app/lib/pages/community/map_page.dart` 已能展示地图、标记、缩放状态，并把 viewport 变化回传给宿主页。
- `app/lib/pages/community/views.dart` 里的探索页已经有地图预览和帖子列表，下方列表就是这次筛选结果最合适的承载位。
- `app/lib/pages/community/repository.dart` 已经能读出帖子经纬度、封面、标题、地点名、标签等筛选所需字段。

结论：这次功能不是做单点详情跳转，而是给社区页补一层“二级筛选状态”，让地图区域和标签共同驱动探索页列表。

## 2. 目标

1. 用户拖动或缩放地图后，探索页下方列表只显示当前地图可视区域内的帖子。
2. 用户点击标签后，在当前地图区域基础上继续筛选出该标签附近的帖子。
3. 标签筛选的半径随地图缩放程度变化，缩得越近，半径越小。
4. 页面上能看见当前筛选条件，并能一键清除标签筛选或回到全量列表。

## 3. 筛选层级

建议把筛选拆成两层：

### 3.1 第一层：地图区域筛选

- 以当前地图 viewport 为准。
- 先筛出当前可视区域内的所有帖子。
- 这是探索页列表的基础数据集。

### 3.2 第二层：标签附近筛选

- 用户点击某个标签后，再从“当前可视区域内”的帖子里做二次过滤。
- 只保留命中该标签的帖子。
- 再用当前地图缩放级别换算出一个半径，过滤“标签附近”的帖子。

## 4. 半径规则

标签附近半径不要写死成单值，建议跟 zoom 挂钩：

- zoom 越小，半径越大。
- zoom 越大，半径越小。
- 可以先用一张离散映射表做第一版，后续再调参。

示例口径：
- zoom 8-9：约 5km
- zoom 10-11：约 2km
- zoom 12-13：约 800m
- zoom 14-15：约 300m
- zoom 16+：约 100m

如果后面要更平滑，可以换成公式，但第一版用表驱动最稳。

## 5. 交互方案

建议这样走：

1. 用户进入探索页，默认展示“当前地图区域内的帖子”。
2. 用户拖动或缩放地图，列表跟着更新。
3. 用户点击某个标签，列表切换成“该标签 + 当前 zoom 对应半径”的结果。
4. 用户再次点击同一标签，或点清除按钮，恢复到第一层区域筛选。
5. 用户切换地图区域后，标签筛选仍按新区域重新计算。

保留两个辅助动作：
- 点列表卡片：继续打开帖子详情 / 3D 预览。
- 长按地图标记：保留原有地点聚合或详情入口，避免把所有入口都压到单击上。

## 6. 代码落点

建议按下面几处拆：

1. `app/lib/pages/community.dart`
   - 增加当前地图区域状态、当前标签状态、当前半径状态。
   - 负责把 viewport 变化和标签点击合成最终列表。
2. `app/lib/pages/community/map_page.dart`
   - 暴露更完整的 viewport 变化信息，最好能拿到 bounds / center / zoom。
   - 让宿主页能知道当前可视区域，而不是只知道中心点。
3. `app/lib/pages/community/views.dart`
   - 在探索页地图卡下面加筛选提示条。
   - 列表数据源改成“区域筛选后 / 标签筛选后”的结果。
4. `app/lib/pages/community/filtering.dart`（建议新增）
   - 放区域判断、标签判断、zoom 到 radius 的映射。
   - 让这块逻辑可单测，避免塞进 `community.dart` 里变臃肿。

## 7. 验收标准

- 地图缩放或平移后，探索页列表会跟着当前区域变化。
- 点击标签后，列表会进一步缩到该标签附近的帖子。
- zoom 变化会影响标签筛选半径。
- 清除标签后能回到区域筛选结果。
- 清除全部筛选后能回到全量帖子。
- 没有结果时能给出可理解的空态，不会黑屏。

## 8. 风险

- 如果 `flutter_map` 当前拿不到稳定 bounds，区域筛选会先退化成“中心点半径近似”，后续再补精确边界。
- 如果帖子数量继续上涨，前端实时筛选会有压力，后续可能要把粗筛放到服务端。
- 如果标签没有统一规范，二级筛选会出现命中不稳定，最好先确认标签字典和归一化策略。

## 9. 建议实施顺序

1. 先补 viewport/bounds 状态和区域筛选函数。
2. 再接入 zoom -> radius 的标签二级筛选逻辑。
3. 然后把探索页列表切到筛选数据源。
4. 最后补空态、筛选条和边界验证。
