# 项目概述

## 项目背景

### 核心解决的问题/现象

该项目旨在对抗物理世界的**"熵增"**过程（即物质的损耗、遗忘与消亡）。它解决了传统
2D
影像（照片/视频）无法记录空间深度、光影及空间感的问题，并将非结构化的三维物理空间转化为可语义检索的数字资产。

### 应用场景

**移动端个人记忆记录：**如记录即将离开的宿舍、租住房或老家。

**医疗辅助与怀旧疗法：**为阿尔茨海默症患者提供沉浸式的回溯体验，缓解认知衰退带来的遗忘。

**城市文化遗产数字化：**通过众包模式记录即将拆迁的历史街道、老字号等。

**空间计算与 XR 适配：**为 Apple Vision Pro 或 Meta Quest
等下一代计算平台提供原生空间资产。

### 目标人群

**感性记录者：**希望超越平面影像，以 1:1 比例留存生活空间的普通用户。

**特定医疗需求者：**需要通过沉浸式场景进行辅助治疗的患者及家属。

**历史与城市记录者：**致力于城市记忆保留与数字档案馆建设的专业人士或志愿者。

### 商业价值与市场洞察

**空间计算蓝海：**随着 XR 设备普及，市场急需从 2D 内容向 3D
原生内容转型，BrainDance 锁定了"低成本空间内容生成"这一痛点。

**数字化情感消费：**在快速城市化进程中，人们对消失的物理空间有极强的情感补偿需求。

## 项目内容

### 项目主体

BrainDance (流光 · 记) 是一款面向移动端的"可检索三维语义记忆引擎"。

### 核心功能

**移动端低成本建模：**利用手机视频流与位姿数据，基于 3D Gaussian
Splatting (3DGS) 技术实现 1:1 高保真三维重建，大幅降低建模门槛。

**空间语义检索 (Spatial RAG)：**集成多模态大模型（Multimodal
LLM），让用户可以用自然语言搜索物理空间（例如问"我的钥匙在哪？"），系统自动定位并引导镜头飞越至对应物体。

**时光剥离 (Time Peeling)：**支持在同一坐标系下叠加不同时间的 3D
切片，实现时空对比与回溯。

**端云协同架构：**手机端负责轻量化采集与查看，云端 GPU 集群（基于
Supabase + Python Worker）负责高性能重建与向量化。

### 数据集与技术栈

**数据形态：**用户采集的视频流、位姿数据，转换后的 PLY/Splat
模型文件，以及经多模态打标后的语义向量。

**技术栈：**Flutter (客户端), Supabase (BaaS/后端即数据库), Python (AI
Worker), 3DGS/Nerfstudio (图形算法), Qwen-VL/LangChain (语义理解)。

## 创新点

### 技术创新点

**3D 语义化 (Spatial RAG)：**不同于单纯的视觉建模，本项目将 3D
场景转化为"可检索的语义数据库"，实现了从"视觉重构"到"意义理解"的跨越。

**低质量视频优化：**针对手机拍摄不稳定的特点，通过 AI
算法介入提高了低质量视频下的 3DGS 模型生成质量。

**端云全自动化管线**：通过 Supabase
实现从移动端快拍到云端训练、再到轻量化 WebGPU 渲染的闭环流程。

### 功能创新点

**"Ctrl+F" 搜索现实世界：**将文本搜索逻辑引入三维空间。

**时光剥离技术：**打破了 3D
模型静态的限制，在三维维度中加入了时间维度，允许用户进行"视觉考古"。

### 其他创新点

**"数字底片"概念：**提出的光场记录（Radiance
Field）具备未来前瞻性，其原始数据可在未来更高分辨率的 XR
设备上重制，具备"抗过时性"。

**反熵哲学导向：**将深奥的物理学概念（熵增）转化为易用的消费级应用工具，赋予了产品独特的人文内涵与品牌深度。

### 模块架构图描述

该架构图采用了经典的三层架构设计，但在实现上完全基于 **Serverless + GPU
Worker** 的现代模式：

**1.  表现层 (Client Layer):**

    基于 **Flutter** 构建，集成了视频流采集与压缩模块。

    核心渲染采用 **WebView + Three.js** 方案，实现了 .splat
格式模型的流式加载与高性能渲染。

    通过 WebSocket
保持与云端的实时长连接，实现任务状态的"灵动岛"级反馈。

**2.  服务与数据层 (Service & Data Layer):**

    基于 **Supabase** 构建，完全去除了传统的 Web 中间件服务器。

    利用 **PostgreSQL** 的 pgvector
扩展，实现了业务数据与高维语义向量的存算一体。

    利用 **Edge Functions** 承载轻量级的语义搜索逻辑，保护 AI Key
不泄露。

**3.  智能计算层 (Intelligence Layer):**

    部署在高性能 GPU 服务器上的 Python 节点。

    **3D 重建管线：**负责从视频到 3D Gaussian Splatting
模型的解算与训练。

    **语义理解管线：**集成 Qwen-VL 多模态大模型，赋予 3D
场景语义理解能力，支撑"空间 RAG"检索。

## 关键技术

### 技术焦点：3D Gaussian Splatting (3DGS) 优化

**风险：**移动端拍摄视频质量参差不齐（抖动、模糊）导致重建失败。

**对策：**在 AI Worker 中加入 OpenCV
图像质量评估过滤，利用 splatfacto 模型进行鲁棒性训练。

### 关键问题：超大文件传输与响应延迟

**对策：**弃用业务服务器转发，采用 S3 Presigned
URL 让客户端直连腾讯云COS；3D 渲染端采用流式加载
(.splat)，实现"边下边看"。

### 设备限制：移动端适配优化

**挑战：**手机拍摄的视频往往存在运动模糊和曝光不准。

**方案：**在 Pipeline 中引入图像质量评估模块，自动剔除低质帧；利用 AI
图像增强预处理视频流，提高 3D 重建的鲁棒性。

## 其他相关技术

**界面设计：**遵循 Material Design 3 规范，提供沉浸式全屏 3D
查看体验，配合 JSBridge 实现 App 原生 UI 与内嵌 WebGL 的双向通信。

**部署方案：**全模块 Docker 化。Supabase 部署在标准服务器；AI Worker
部署在带 NVIDIA CUDA 支持的 GPU 节点。

# 项目计划

## 可行性分析

### 技术可行性分析

Nerfstudio 与 gsplat 等底层框架已成熟；多模态 LLM (Qwen-VL/GPT-4o)
的视觉理解能力已达到商用级别。

### 资源可行性分析

团队已具备 Flutter、Supabase、Typescript、Python
的全栈开发能力，且拥有支持 CUDA 的显卡计算资源。

随着 Apple Vision Pro 引领空间计算时代，高保真的原生 3D
内容生成工具正处于爆发前夜，且"数字海马体"的人文内涵具有极强用户黏性。

# 总结与展望

## 项目总结

BrainDance 成功地将前沿的 3DGS 技术与多模态 RAG
结合，将"平面影像"升级为"三维语义记忆"，为人类对抗熵增、保存记忆提供了新的可能。

## 后续扩展

**生成式 3D：**结合 LGM 模型，实现从单张照片直接生成 3D 空间。

城市级众包：建立分布式节点，通过千人拍摄共同拼凑出一座城市的数字方舟。

**WebXR 支持：**直接在 VR 头显中浏览记忆空间。

**生成式补全：**利用 AIGC 技术修补扫描过程中的盲区。
