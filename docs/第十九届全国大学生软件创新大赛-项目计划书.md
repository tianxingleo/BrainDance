1.1.1	核心解决的问题/现象
1. 对抗物理世界的“熵增”与遗忘。 本项目旨在对抗物理世界的“熵增”过程（即物质的损耗、遗忘与消亡）。它解决了传统 2D 影像（照片/视频）无法记录空间深度、光影及空间感的问题，并将非结构化的三维物理空间转化为可语义检索的数字资产，为用户建立抵抗遗忘的“数字海马体”。
2. 解决三维重建的“反馈延迟”与“盲盒体验”。在现有的消费级应用中，高保真三维建模通常是一个“离线”且“高延迟”的过程。用户在拍摄后往往需要等待数十分钟甚至数小时才能看到结果，这种割裂体验，使得用户无法即时确认拍摄素材的有效性（如是否漏拍、模糊）。本项目致力于解决这一痛点，提供“移动端秒级预览，云端异步精修”，让三维记录像拍照片一样简单、即时。
3. 行业技术现状。近年来，NeRF 与 3D Gaussian Splatting (3DGS) 等技术的发展，虽然使得基于普通图像的高保真重建成为可能，但目前的开源生态仍多集中于“高质量慢速离线训练”，缺乏移动端GPU/NPU适配的“秒级推断”方案。与此同时，虽然 Qwen3-VL 等多模态大模型在视觉理解上取得突破，但将其与 3D 空间进行语义对齐的工程实践尚处于空白阶段。本项目正是为了填补这一“从算法原型到移动端即时服务”的工程落地缺口。[天李14.1]

1.1.6	核心功能
“近零幻觉”端侧 RAG 问答引擎：系统无缝集成了微调过后的 Qwen3-1.7B-GGUF 端侧大模型，不仅能对本地的空间记忆资产进行高速的纯离线的自然语言即时查询，更显著降低了云端模型易发的幻觉与数据上云隐私风险。
移动端低成本建模：
即时空间预览：引入 SHARP轻量化模型，在用户完成拍摄的5秒内，即可预览具备初版 3D 场景。用户无需等待云端耗时的精密解算，即可确认拍摄内容的完整性并进行初步交互，真正实现“所见即所得”的即时性服务。
渐进式高保真重建：在即时预览的同时，云端启动基于 Nerfstudio 的高保真训练管线（约 10 分钟），待计算完成后自动无缝替换为精细模型，兼顾“速度”与“质量”。 [天李20.1]
时光剥离 (Time Peeling)：支持在同一坐标系下叠加不同时间的 3D 切片，实现时空对比与回溯。
端云协同架构：手机端负责轻量化采集与极低延迟的算力量化 AI 交互处理，云端 GPU 集群（基于 Supabase + Python Worker）负责处理长异步链路的高性能 3D 重建。

1.1.8	技术创新点
1. 基于超大模型数据合成的端侧模型定向增强（定向知识蒸馏）
问题背景：当前 AI 落地移动端面临着“隐私与智能的矛盾”。用户的日志、个人日程和居家照片极其私密，存在极大的隐私泄露风险，必须完全在本地端运行推理。但手机算力受限（通常只能部署不超过 2B 的端侧模型），而小模型天生逻辑较弱，在空间 RAG 任务中极易产生幻觉和指令脱轨。
核心创新：
引入前沿的 Teacher-Student 范式（知识蒸馏），离线阶段通过超大模型（GPT-5.4 级）强大的逻辑推理能力，构建针对本地隐私 RAG 场景的高质量“合成数据集（Synthetic Data）”。发掘真实环境中的困难样本（Hard Example Mining，如只存在部分命中的场景），生成精准纠偏补丁。
在部署阶段，采用 LoRA (Low-Rank Adaptation) 对 Qwen3-1.7B 进行定向有监督微调（SFT），将“教师”的强对齐边界、格式化能力“蒸馏”进本地小模型。
最终成果：让移动端 1.7B 级小模型具备了**极高可靠性**的指令遵循能力与“近零幻觉”拒答分析表现，在极少的算力下，实现了本地断网的毫秒级空间检索与语义推断链路保护。

2. 端侧低 bit 极限部署与重要性矩阵保真 (Edge Quantization with imatrix)
问题背景：虽然端侧模型小，但原版 1.7B 仍然超过 3GB，无法被主流如 OPPO 等安卓设备的内存所常驻加载。且单纯的权重量化会导致严重的性能退化，特别是在严格的数据问答提取场景中。
创新突破：
除了基础的 GGUF 量化转换，本项目团队创造性引入重要性矩阵（Importance Matrix，imatrix）技术。通过大规模计算模型运行过程中的激活激增强度，校准 Q5_K_M 低 bit 结构的权重分布。
经此方法，可将原模型平缩至 1.2GB 内（完全适配主流移动端内存瓶颈），但在团队构建的 Strict-OOD 强约束多源回归数据集上，核心实体召回等相关指标衰减控制在 1% 内实现“体积与智商”的完美平衡。

3. AI质检驱动的鲁棒性提升 (独创)
问题背景：移动端拍摄视频除存在抖动、模糊等数据质量问题外，传统 Incremental SfM（如 COLMAP）存在严重的算法不稳定性：对初始帧选择极其敏感，在弱纹理或视角变化快时，常因初始化失败或匹配链断裂导致重建成功率呈概率性分布（失败率高达 60%+）。
创新方案：
引入 GLOMAP 全局优化架构，摒弃传统增量式重建对“第一张图片”的依赖
Tree-based 拓扑匹配策略，确保在局部匹配丢失时仍能通过全局约束找回位姿
集成多模态大模型Qwen-VL多模态大模型进行场景质量评估，自动剔除低质帧（高模糊、过曝/欠曝帧）
自适应训练：splatfacto模型针对低质视频优化[天李23.1]
效果对比：
传统方法：成功率约40%（1080p视频，30fps）
本方案：成功率提升至95%+（同等条件）
训练时间：1080p30fps 3分钟视频为数据源，从约1.5小时缩短至约10分钟（通过独创算法优化与最新Blackwell架构显卡适配，相比与知名桌面端商业3dgs软件Postshot）

4. 3D场景语义化 (Spatial RAG)
行业现状： 现有3D重建仅关注"形"（几何），忽略"意"（语义），导致重建后的场景无法检索、无法理解。
创新突破：
多模态AI理解：多模态大模型Qwen-VL分析场景内容，生成自然语言描述
向量化存储：pgvector存储1536维语义向量
自然语言检索：用户提问"我的钥匙在哪"，系统自动定位3D空间中的物体
场景自动标注：识别物体类别（桌子、椅子、电脑等）并打标
技术指标：
语义检索准确率：Top-5命中率达92%
响应时间：<500ms（向量搜索 + 相似度计算）
支持场景类型：室内、室外、建筑、自然景观

5. Serverless端云协同架构
传统方案痛点：
需要自建Redis/MinIO/Nginx中间件
运维复杂度高，部署周期长
成本高昂（专用服务器）
创新架构：
完全基于Supabase BaaS（Backend as a Service）
零中间件：PostgreSQL替代Redis，Storage替代MinIO
自动扩展：按需计费，无需手动扩容
快速部署：30分钟完成环境搭建
成本优势：
部署时间：从3天缩短至30分钟
运维成本：降低70%（无专用服务器）
扩展能力：支持从1到1000用户的弹性扩展

4.	基于 SHARP 的“快慢双链”渐进式重建架构
问题背景： 传统的 3DGS 重建流程通常需要数分钟至数十分钟，这种“黑盒等待”严重割裂了用户的探索体验，无法满足 “即时满足”需求
创新方案：
快链路： 利用SHARP模型作为推断核心。该模型无需迭代训练，直接通过 Encoder-Decoder 网络从输入视频帧单次前向传播预测高斯参数，实现1s（显存）至5s秒（内存） 的极速重建
慢链路： 利用传统3DGS生成手段使用Nerfstudio进行高质量重建

采用高可用云原生架构
针对移动端并发上传和高算力消耗的矛盾，本方案设计了基于消息队列的异步解耦架构，确保系统的高可用性与弹性伸缩能力：
异步解耦 ： 引入消息队列作为任务缓冲区。用户上传视频后立即返回响应，任务元数据写入队列，避免因长耗时重建任务阻塞前端请求，支持高并发（约每秒1000次）提交。
主动拉取机制： 后端 ai_engine 摒弃传统的推送模式，采用 Worker Pull 机制主动从队列获取任务。这实现了削峰填谷，防止瞬时流量压垮推理节点，保证重建过程的稳定性。
弹性伸缩与部署： 核心计算模块部署于 PAI (Platform for AI)。利用云原生特性，根据队列积压情况自动扩容/缩容计算实例。在保证算力供给的同时，最大限度降低闲置资源成本。

2.3	关键技术[yw29.1]
2.3.1	技术焦点：3D Gaussian Splatting (3DGS) 优化
风险：移动端拍摄视频质量参差不齐（抖动、模糊）导致重建失败。
对策：在 AI Worker 中加入 OpenCV 图像质量评估过滤，利用 splatfacto 模型进行鲁棒性训练。
2.3.2	关键问题：超大文件传输与响应延迟
对策：弃用业务服务器转发，采用 S3 Presigned URL 让客户端直连腾讯云COS；3D 渲染端采用流式加载 (.splat)，实现“边下边看”。
2.3.3	设备限制：移动端适配优化
挑战：手机拍摄的视频往往存在运动模糊和曝光不准。
方案：在 Pipeline 中引入图像质量评估模块，自动剔除低质帧；利用 AI 图像增强预处理视频流，提高 3D 重建的鲁棒性。
