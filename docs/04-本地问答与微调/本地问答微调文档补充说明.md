# BrainDance 本地问答微调文档补充说明

> 本文档用于把 `Qwen3-1.7B` 微调实践（Part 16-19）整理成正式文档入口，便于开发、联调和答辩说明。  
> 状态声明：以下内容属于**实验/调试链路**，当前**尚未并入正式产品主流程**。

---

## 1. 目标与边界

本轮微调不是把用户事实写进参数，而是训练模型“如何基于检索证据回答”：

- 有命中时稳定回答
- 无命中时明确拒答
- 保持短答风格，降低重复输出

能力边界：

- 目前主要在 `ai_engine/finetune_qwen3` 目录下验证
- 通过 CLI 与评测脚本运行
- 尚未接入 App 正式业务链路

---

## 2. 阶段演进（Part 16-19）

- **Part 16**：补齐 route 级可观测性（query_class / retrieval_route / answer_route）
- **Part 17**：聚焦 `object_lookup` 检索专项优化，不开新 LoRA
- **Part 18**：强化 formatter 路由，提升真实交互回答可读性
- **Part 19**：沉淀最小可用本地问答入口 `local_qa_cli.py`

---

## 3. 目录与关键脚本

主要目录：

- `ai_engine/finetune_qwen3/data`：训练/评测题集
- `ai_engine/finetune_qwen3/scripts`：训练、评测、调试、CLI
- `ai_engine/finetune_qwen3/logs`：汇总与回归输出

关键脚本：

- `train_lora_sft.py`：LoRA SFT 训练
- `run_real_chain_debug.py`：真实链路调试
- `interactive_debug_chat.py`：交互调试与反馈标注
- `local_qa_cli.py`：最小本地问答入口
- `evaluate_object_lookup_part17.py`：Part 17 评测
- `evaluate_experience_part18.py`：Part 18 评测
- `summarize_interactive_debug_routes.py`：路由聚合汇总

---

## 4. 快速命令（实验链路）

### 4.1 本地问答 CLI

```bash
# 单轮问答
python ai_engine/finetune_qwen3/scripts/local_qa_cli.py --question "我最近拍了什么？"

# 交互模式
python ai_engine/finetune_qwen3/scripts/local_qa_cli.py

# 链路追踪 + 证据预览
python ai_engine/finetune_qwen3/scripts/local_qa_cli.py \
  --question "最近拍到过什么地球仪相关画面？" \
  --show_trace --show_evidence
```

### 4.2 测试回归

```bash
pytest -q tests/test_part17_object_lookup.py tests/test_part18_formatters.py tests/test_local_qa_cli.py
python -m py_compile \
  ai_engine/finetune_qwen3/scripts/run_real_chain_debug.py \
  ai_engine/finetune_qwen3/scripts/evaluate_experience_part18.py \
  ai_engine/finetune_qwen3/scripts/local_qa_cli.py
```
