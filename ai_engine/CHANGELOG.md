## [2.0.0] - 2026-01-19

### 🏗️ 架构重构

本次更新对整个 AI 引擎进行了全面的架构重构，采用设计模式提升系统的可扩展性和可维护性。

- **引入策略模式重构流水线架构**：废弃原有的单体 pipeline.py，采用策略模式重新设计，实现了不同业务场景下流水线的灵活切换和统一管理。

- **新增 Pipeline 基础抽象类**：创建 BasePipeline 抽象基类，定义了所有流水线必须实现的标准化接口（run、log、cleanup），确保不同实现的一致性。

- **实现 PipelineFactory 工厂类**：开发工厂类负责根据任务类型（task_type）动态实例化具体的 Pipeline 实例，支持运行时的流水线路由和分发。

- **建立独立的 pipelines/ 目录**：新建目录专门存放不同类型的业务流水线实现，包括视频 3DGS 生成和多图重建等独立模块。

- **迁移和优化核心流水线**：将原视频 3DGS 生成逻辑封装为 Video3DGSPipeline，新增 MultiImagePipeline 骨架用于多图重建任务。

- **升级 Worker 调度逻辑**：重构 worker.py，移除硬编码的 pipeline 调用，集成 PipelineFactory 实现基于 Supabase 任务配置的动态分发。

- **实现动态配置初始化**：引入 Context Context 机制替代全局静态配置，支持根据任务参数动态初始化运行环境。

- **完善错误处理机制**：增强 RAG 资产入库逻辑，添加完整的错误处理和重试机制，提升系统稳定性。

### ⚙️ 配置与修复

- **修复配置缺失问题**：修复 PipelineConfig 类缺失 iterations 属性导致 fast_mode 关闭时崩溃的 Bug，添加默认值 30000。

- **优化图像处理**：增强图像清洗逻辑，提升抽帧后的图片质量过滤能力。

### 📝 文档完善

- **全量代码文档化**：为项目内所有 Python 模块（core/、modules/、utils/）添加标准化的中文文件头注释。

- **模块功能说明**：详细描述每个模块的功能职责和核心逻辑，大幅提升代码的可维护性和可读性。

## [1.5.0] - 2026-01-16

### 🤖 RAG 语义检索系统

引入基于向量数据库的检索增强生成（RAG）能力，使引擎具备"记忆"和"语义检索"功能，支持通过自然语言搜索历史 3D 资产。

- **启用 pgvector 向量扩展**：在数据库层面启用 pgvector 扩展，创建 model_assets 表用于存储 3D 资产的元数据与向量表示。

- **实现唯一性约束**：为 scene_id 添加唯一性约束，防止重复运行任务导致知识库出现重复数据。

- **开发高级搜索函数**：实现 match_model_assets RPC 函数，支持基于余弦相似度的语义搜索，并增加时间范围过滤功能。

- **集成向量化服务**：接入阿里云 DashScope text-embedding-v2 接口，将场景描述、物品清单及标签转化为 1536 维向量。

- **优化 Embedding 策略**：通过加权文本构建策略，重复核心主体并结构化拼接描述+物品+标签，提升搜索召回率。

- **实现 Upsert 机制**：将入库逻辑从 insert 升级为 upsert，支持基于 scene_id 的自动去重与更新。

- **开发意图识别**：引入 LLM（Qwen-Plus）对用户自然语言进行解析，自动提取搜索关键词与时间范围。

- **实现混合检索**：开发"语义向量 + SQL 元数据过滤"的混合检索逻辑，提供精准的资产搜索体验。

- **打通数据流**：在 pipeline 中增加场景描述和物品提取逻辑，worker 自动调用知识库模块将新生成的模型资产注册到数据库。

### 🧠 AI 场景分析

在 3DGS 生成管线中增加基于 LLM 的场景分析环节，实现从"盲目生成"到"智能评估"的升级。

- **新增 AI 质检模块**：创建 SceneAnalyzer 类，封装阿里云 DashScope API 调用逻辑，实现智能场景质量评估。

- **实现动态评分机制**：随机抽取视频帧作为输入，利用 Qwen-VL 对拍摄环境（光照、纹理、模糊度）进行多维度评估，生成 0-100 分的质量评分。

- **配置评分阈值**：支持通过 .env 中的 MIN_QUALITY_SCORE 阈值决定是否放行任务，自动拦截低质量素材。

- **扩展数据库 Schema**：在 processing_tasks 表中新增 quality_score（评分）、quality_reason（评价）和 tags（标签）字段。

- **实现元数据回写**：Worker 接收 Pipeline 返回的元数据，将 AI 的分析结果实时回写到 Supabase 数据库，即使任务失败也能看到拒单理由。

- **优化 Pipeline 流程**：在抽帧与解算之间插入 AI 质检步骤，实现元数据透传机制，确保分析结果能传递给 Worker。

## [1.4.0] - 2026-01-13

### 📦 模块化工程架构

将原有超过 800 行的单文件脚本重构为模块化的工程架构，解决维护困难、复用性差的问题。

- **建立标准目录结构**：引入 src/ 源码目录，实现代码与配置、数据的物理隔离。

- **核心模块拆分**：将原 process_3dgs.py 拆分为多个独立模块：
  - GlomapRunner：封装 COLMAP/GLOMAP 位姿解算逻辑
  - AISegmentor：封装 Qwen-VL + YOLO + SAM 的语义分割流水线
  - NerfstudioEngine：封装 3DGS 训练与导出逻辑
  - ImageProcessor：独立图像预处理（模糊检测、降采样）逻辑

- **通用工具抽离**：创建 utils/ 目录，抽离通用工具函数：
  - cv_algorithms.py：纯视觉算法（Mask 清洗、显著性检测）
  - geometry.py：3D 几何计算（自适应 Collider 计算）
  - ply_utils.py：点云后处理（分位数切割）
  - common.py：通用辅助函数

- **配置管理优化**：引入 PipelineConfig（@dataclass）替代全局变量，支持自动路径推导，统一项目配置管理。

- **实现软依赖处理**：在 AISegmentor 中实现软依赖逻辑，在无 AI 库环境下可自动降级运行。

- **统一入口重构**：重写 main.py，通过 Pipeline 类串联各模块，实现"配置-执行"分离。

## [1.3.0] - 2025-12-20

### ☁️ 云端任务队列集成

完成从本地脚本向云原生架构的转型，实现基于 Supabase 的分布式任务处理系统。

- **架构解耦重构**：将原 process_3dgs.py 拆分为 worker.py（负责 IO 与调度）和 pipeline.py（负责核心算法），实现业务逻辑与控制逻辑分离。

- **实现任务轮询机制**：在 worker.py 中实现 processing_tasks 表的持续监听（Polling），自动获取 pending 状态任务。

- **构建全自动化流水线**：实现从 Storage 下载视频 → 执行 3DGS 管线 → 上传 PLY 模型与 transforms.json 的全闭环流程。

- **状态流转管理**：实现任务状态流转（pending → processing → completed/failed）的实时数据库更新。

- **日志系统升级**：改造 pipeline.py，引入 log_callback，支持将底层算法的执行进度实时冒泡至上层。

- **修复并发日志问题**：修复日志同步时的"读写冲突"导致的空日志问题，采用"本地内存缓冲 + 全量覆盖"策略确保高并发下日志不丢失。

- **环境变量管理**：引入 .env 文件管理敏感信息（Supabase URL/Key）及核心参数，支持无需修改代码即可调整训练质量与速度。

- **实现模型共享缓存**：修复 AI 辅助模型（YOLO/SAM）重复下载问题，将下载路径重定向至公共目录。

- **增加自动清理**：增加 finally 块的清理逻辑，任务结束后自动删除临时视频与中间产物，防止磁盘爆满。

- **双模式入口**：重写 main.py，支持通过命令行参数切换「本地调试模式」与「云端监听模式」。

## [1.2.0] - 2025-12-17

### 🧠 AI 增强功能

引入多模态 AI 能力，大幅提升 3DGS 生成的智能化水平和处理精度。

- **新增 SHARP 单图 3D 生成**：实现基于 apple/ml-sharp 的单图生成 3DGS 自动化工作流，支持从单张照片快速生成 3D 模型。

- **引入场景分析模块**：创建 analyze_scene_smart.py，利用多模态大模型（Qwen-VL-Max）对采集的图像数据进行深度理解与质量评估。

- **实现智能筛选去重**：基于语义和画质的多图联合分析，自动剔除模糊、重复或无效的帧，从相似视角的图片组中优选最佳观测位姿。

- **识别拍摄策略**：自动识别拍摄轨迹类型（环绕物体 Orbiting vs 场景扫描 Scanning），检测场景封闭性（Enclosed vs Open）与主体数量。

- **开发质量评估系统**：集成画质评估维度，包括噪点水平、光照条件（直射/漫反射）及焦段估计，检测动态干扰物（手指遮挡、拍摄者阴影）。

- **生成元数据报告**：输出结构化的 JSON 报告，包含全局场景摘要（scene_summary.json）和单图详细描述，所有描述强制使用中文。

- **升级分割管线**：从 segment-anything-2 升级至 SAM 3，引入 YOLO-World v2 + SAM 3 双阶段管线，显著提升边缘切割精度和背景分离度。

- **优化细长物体分割**：实现"五点梅花阵 + 四角负采样"的多点提示策略，放宽长宽比限制至 15.0，新增最大面积拦截逻辑。

- **增强清洗质检**：将实心度阈值从 0.88 下调至 0.75，允许物体边缘存在一定的凹陷或缺口，修复"僵尸文件"隐患。

### ⚙️ 架构重构

- **配置中心化**：引入 PipelineConfig（@dataclass）替代全局变量，统一管理项目路径、环境变量及运行参数，利用 __post_init__ 自动计算衍生路径。

- **全流程模块化**：将原 run_pipeline 巨型函数拆解为四个独立职责的类（ImageProcessor、GlomapRunner、AISegmentor、NerfstudioEngine），提升代码可读性与可维护性。

- **修复 GLOMAP 崩溃**：解决 Conda 环境与系统级 GLOMAP 二进制文件的库冲突（SQL logic error/SIGABRT），增加环境隔离逻辑。

- **优化二进制查找**：恢复优先使用 Conda 环境内 colmap 的逻辑，避免强制使用系统 colmap 导致的数据库兼容性问题。

## [1.1.0] - 2025-12-10

### ⚡ 性能大幅优化

通过算法升级和系统调优，实现稀疏重建速度提升 60 倍（从 5 分钟降至 5 秒），并解决显存溢出等关键问题。

- **替换 SfM 后端为 GLOMAP**：从 colmap mapper（增量式 SfM）替换为 glomap mapper（全局式 SfM），在大规模场景下速度更快，对弱纹理或难样本的鲁棒性更强。

- **集成 VGGT 模型**：引入 Meta 的 VGGT-1B 模型直接从图像序列预测相机位姿和深度图，无需迭代优化，进一步加速处理流程。

- **实现显存防爆**：针对 RTX 5070（12GB）等显存受限设备，在推理结束后立即手动释放巨大的中间变量并清空 CUDA 缓存。

- **采用混合分辨率策略**：使用"加载时高分（1024px）+ 推理时低分（518px）"的混合分辨率策略，在保证点云精度的同时降低 Transformer 计算开销。

- **动态点云过滤**：改为动态 Top-K 策略（保留置信度最高的 10w 个点），解决纹理较弱或图片较少场景下点云为空的问题。

- **相机参数还原**：增加针对 Padding 和 Resize 的逆变换逻辑，确保 VGGT 在方形图上预测的内参能正确映射回原始长宽比的图像。

- **解决环境兼容**：通过 SETUPTOOLS_USE_DISTUTILS=stdlib 解决 Conda 环境下 gsplat/nerfstudio 运行时触发的 distutils 断言错误。

- **启用 TF32 加速**：支持 RTX 50 系列 TensorFloat-32（TF32）加速，提升计算效率。

### 🔧 依赖修复

- **GCC 14 兼容性补丁**：解决 GCC 14 内置 __float128 支持与 Boost 1.82 的定义冲突（redefinition of numeric_limits）。

- **系统头文件可见性**：解决 Conda 编译器屏蔽 /usr/include 导致找不到 GL/gl.h 和 CGAL 头文件的问题。

- **ABI 不兼容修复**：采用"混合挂载"策略——使用系统级 Boost 配合 Conda 级 Glog/Ceres，通过软链接替换头文件实现 ABI 统一。

- **SQLite 版本冲突解决**：修复 GLOMAP 运行时崩溃（SQLite error: SQL logic error），强制注入 LD_LIBRARY_PATH 将 Conda 的 lib 目录优先级提至最高。

## [1.0.0] - 2025-12-03

### 🎉 首个正式版本

完成 BrainDance AI Engine 的基础架构搭建和核心功能实现，支持从视频输入到 3DGS 模型输出的完整流程。

- **实现基础 3DGS 流程**：完成视频 → 图像预处理 → COLMAP 位姿解算 → 3DGS 训练 → 模型导出的完整流水线。

- **COLMAP GPU 加速**：成功编译 GPU 版本 COLMAP，强制伪装成 RTX 40 系显卡（compute_89）以适配 RTX 5070，实现位姿解算速度大幅提升。

- **智能图像清洗**：实现基于九宫格的模糊检测算法，支持智能去噪和均匀采样降维，自动过滤低质量图像。

- **质量熔断机制**：新增日志实时分析，检测到"No convergence"或匹配率低于 35% 时自动终止任务，防止无效计算。

- **图像清洗算法升级**：实施"质检+采样"双重过滤策略，基于九宫格拉普拉斯方差检测和动态阈值保留前 85% 图片。

- **自动重试机制**：在 process_3dgs_cut.py 中增加 3 次重试循环，如果匹配率低或失败，自动清理 database.db 和 sparse 目录后重试。

- **高敏感度特征提取**：针对弱纹理物体，大幅降低 SIFT 阈值并放宽边缘限制，强制开启 GPU 加速。

- **词汇树/广域匹配**：使用 vocab_tree_matcher，并增加回环检测逻辑，提升重建成功率。

- **修改数据解析器**：将 ns-train 的数据解析器从 colmap 更改为 nerfstudio-data，解决物理删除图片后的索引问题。

- **禁用自动缩放**：添加 --auto-scale-poses False 和 --orientation-method none，完全信任 COLMAP 的稀疏点云姿态。

- **实现坐标转换**：开发坐标转换功能以提供 WebGL 支持，将 3D 模型坐标转换为 Web 友好格式。

- **智能场景识别**：实现本地拍摄类型识别（Orbiting/Scanning）、降低噪声、自动裁剪模型大小等功能。

### 🏗️ 工程架构

- **建立项目结构**：创建完整的目录结构，包括 src/、demo/、docs/ 等标准化目录。

- **完善 .gitignore**：配置 git 忽略规则，排除临时文件、环境配置和模型权重文件。

- **环境配置管理**：引入 .env 和 python-dotenv 管理环境变量（API Keys）。

- **开发文档**：创建 README.md 和技术文档，提供快速启动指南和 API 说明。

### 🧪 核心模块

- **图像预处理**：实现 FFmpeg 抽帧和基于拉普拉斯方差的模糊检测算法。

- **位姿解算**：集成 COLMAP 进行特征提取、匹配和稀疏重建。

- **3DGS 训练**：基于 Nerfstudio 的 Splatfacto 算法进行高斯泼溅模型训练。

- **模型导出**：实现 PLY 格式的模型导出和点云后处理。
